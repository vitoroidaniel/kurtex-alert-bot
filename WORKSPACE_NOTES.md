Case Workspace V13
==================
Smartsheet-inspired Board and Grid. Data is read from existing /api/cases and details use existing openCase modal. Search, group, status filters, view switch and refresh are functional. No new server-side write endpoints were invented. Notes and attachments are accessed through the existing full case modal, and editing or dragging cards is not implemented. API loads up to 2000 cases; a backend pagination/search plan is needed for larger histories. Browser visual testing required.
