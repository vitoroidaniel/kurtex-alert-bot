# UI ownership

Scope: shared presentation and reported maintenance case management. Flask routes own authorization and validation; `backend/storage/case_store.py` owns durable lifecycle transitions. Product context: the user's October 10 decision, `README.md`, and the bot's reporting and closing flows.

| Capability | Canonical owner | Contract |
| --- | --- | --- |
| Period filters | `static/js/core/state.js` | Existing period handlers retain API semantics; leaderboard period changes reset ranking pagination and expose pressed state. |
| Filter presentation | `static/css/core/kurtex-v23.css` | One shared segmented style across existing filter groups. |
| Select/Listbox | `static/js/core/custom-select.js` | Preserve existing shared select enhancement; no replacement introduced. |
| Scrollbar | `static/css/core/kurtex-v23.css` | Global inherited theme styling, with system forced colors. |
| Leaderboard | `static/js/features/views.js`, `static/css/core/chrome.css` | Metrics precede the period and rank-by filters. Ranking uses a comparable table and existing paging/calculations; insights and theme-aware charts share the selected period. Rank-by uses the shared select owner. |
| Theme | `static/js/core/state.js`, dashboard CSS tokens | Stored preference controls document theme; legacy aliases resolve to canonical surfaces. |
| Agent directory | `static/js/features/agents-v23.js`, `/api/agents`, `/api/agent` | Server-owned identity, role, statistics, status/search filters and chronological sort; 20 cases per page. Ignore stale responses when selecting another agent. |
| Agent activity presentation | `static/js/features/agents-v23.js` | Five compact metrics without average response; columns Driver, Group, Case / Unit, Reported, Status, Actions. Clear search returns focus to its input. |
| Case Workspace | `static/js/features/case-workspace.js`, `/api/cases?filter=workspace` | Only maintenance reports with open/assigned/reported status and no close timestamp. Independent filters for query, status, priority, equipment, sort and grouping. Closed reports remain in the unchanged Cases history. New reports appear through existing polling. Counts describe loaded reports. |
| Report writes | `/api/workspace/cases`, `backend/storage/case_store.py` | Current registered membership, Cases page permission and session CSRF token are required. Agents manage their own reports; super admins and developers manage all. New reports are assigned to the creator. Create retry keys and repeated closes are idempotent. Revision conflicts reject stale edits. Save failures preserve entered values and never claim success. |
| Report lifecycle | `case_store._close_record`, `case_store.save_maintenance_report` | Workspace and Telegram share the Done transition and timing fields. Close preserves report notes and appends actor history. Report submission saves fields under the same lock and cannot reopen a case closed concurrently. No deletion or Telegram dispatch is performed by Workspace writes. |
| Forms and confirmation | Shared `.modal-overlay` shell, `custom-select.js`, `case-workspace.js` | New/edit/note forms use labeled fields and native required validation. Close requires an app-owned confirmation explaining retention. Pending writes disable controls; errors retain the form. Escape, focus trapping and focus return reuse the shared modal owner. |
| Full case | `case-workspace.js` | Open full case stays within Workspace and uses the same selected report, authorization and actions. Back preserves board query, filters and grouping. Description, notes, history, attachments and related loaded reports contain real data only. |
| Retained case history | `views.js`, `case-workspace.js` | The existing Cases detail modal displays retained report comments, workspace notes and actor history through the same renderers used in Workspace. Closed reports remain searchable with status Done. |
| Global clock | `static/js/core/app.js` | Preserve America/Chicago time, date, and connection status in the main top bar. |
| Shell and filter summaries | `static/js/features/ui-refinements.js`, `static/css/core/chrome.css` | One compact top bar in document flow; no duplicate page heading or introductory hero copy on operational tabs. Home restores Report/Print/Export/Refresh. Agents hides Report and Refresh. Workspace keeps its own export semantics. Search queries remain in memory; workspace view/group persist. |
| Notifications | `static/js/features/notifications.js`, `static/css/core/chrome.css` | All/Unread/Alerts filters have pressed state. Case links and mark-read actions are separate native buttons. Bell expanded state tracks opening, outside dismissal and Escape; Escape restores focus. Mark-all failures preserve unread records and expose feedback. Existing preferences and case watchers remain authoritative. |
| Mobile workspace inspection | `static/js/features/case-workspace.js` | Non-modal full-width in-page inspector replaces board content on phones; close restores the matching case button and page scroll. Filters stay intact. Header and actions remain outside the scrolling detail body. |
| Theme compatibility | `static/css/core/theme.css`, `static/js/core/state.js` | HTML data attribute and legacy body class stay synchronized; high-specificity Home surfaces follow canonical dark tokens. Desktop workspace opens its first available case once; phones wait for a selection. |

Verification for this change is limited to source inspection at the user's request: no local tests, app startup, browser checks or audits were run. Runtime visual fidelity, keyboard behavior and write workflows remain unverified.
